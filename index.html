Вийти з акаунту
Щоб увімкнути збереження у Firebase:
  1. Створіть проєкт на console.firebase.google.com
  2. Увімкніть Authentication → Sign-in method → Email/Password
  3. Створіть Firestore Database (у режимі production)
  4. У налаштуваннях проєкту скопіюйте обʼєкт firebaseConfig і вставте його у файл — блок firebaseConfig у <script>
  5. Додайте домен свого сайту в Authentication → Settings → Authorized domains
